## Five best payoff/effort changes

1. Remove the live EOU raw-token log (`main.swift:2858`) and sanitize sidecar diagnostics before Rust logs them.
2. Gate release publication on tests/CI for the exact SHA rather than build success alone.
3. Scope Vitest discovery to `src/**` so ignored agent tooling cannot enter product tests.
4. Make Swift sidecar status smoke and expected binary existence hard build failures.
5. Run/check installer admission gates and each upload exit code in the manual Windows release path.
