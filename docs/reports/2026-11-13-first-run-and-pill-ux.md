# First run and pill: make the first minute dependable

**13 November 2026 · Source-code and primary-source audit · Not a hands-on usability test**

**Approve 1–3 first:** prepare a suitable engine while the person grants permissions, prove we can hear them, then make their first sentence land. Premium should mean confidence, not more animation.

This supplements [yesterday’s competitor overview](2026-11-12-audit/competitors.md), not its pricing/platform matrix. **[UNVERIFIED]** means evidence missing; recommendations are proposals. Dated user reactions below are within **13 November 2025–13 November 2026**. Undated vendor documentation is current published guidance, not proof of release date. Older sources are labeled. Vendor timings and individual opinions are not benchmarks.

Windows substitutes mic Continue for permission Continue. Download, verification, permission round trips, shortcut registration, engine startup and recognition are waits; none was timed. References: table above.

**Reading burden:** not a single mandatory essay, but source architecture → model administration/GPU → permissions → hotkey semantics → telemetry before established value. Long optional detours: cloud/LAN, shortcut editor, What’s shared. Keep the concise permission reasons and real practice field. References: components above.

**Commercial caveat:** these onboarding components expose no sign-in/start-trial step. `src/App.tsx` mounts `LicenseProvider`; `src/contexts/LicenseContext.tsx::checkStatus` invokes status asynchronously with a 60-second command timeout. **[UNVERIFIED]** clean-install entitlement/backend commercial gates were not exercised. “Private, offline, free” is not proof of a perpetual-free license. Preserve the founder decision: trial starts only on explicit start-trial action, never sign-in.

**Feedback is a separate layer, not additional recording states.** Complete copy families (`src/pill/feedback.ts`):
- **Blockers:** Trial ended; Couldn’t verify your license (two kinds); No voice engine set up; Cloud key missing/rejected; Soniox storage is full; Microphone access is off; No microphone; Mic in use by another app; Allow Accessibility; Getting ready… . Actions: Activate, Recheck, Set up, Fix key, Clean up, privacy settings, Choose mic. Persistent except Getting ready (3.2 s).
- **Recovery:** provider unreachable; Network offline; model isn’t downloaded; remote is offline; Recording recovered/interrupted; No speech heard; Mic disconnected · no audio captured. Retained cases say Recording kept and explain temporary/7-day/30-second retention. Retry/alternate-model/Transcribe anyway depend on readiness; failed retry offers Retry again, possible Try another model, Delete audio. Closing does not extend the audio lease.
- **Notes:** Mic disconnected · using the [duration] we got; Couldn’t keep the recording; Your mic sent silence — is it muted?; Pasted untranslated · translation failed; Using [fallback]; GPU unavailable · using the CPU; Pasted unpolished · Polish [timed out/rate limited/unavailable offline/kept the original/failed]. Usually 3.5 s; storage/silent-after-stop 5 s; live silence persistent.
- **Notices:** Finishing…; Polish on; · not polished; Set up an AI model to use Polish; Formatting-mode shortcuts were retired; Still listening…; two stopped-after-five-minutes-of-silence variants; Recording failed; Copy failed; Transcription failed · try again / retry from History; Hold on…; No speech heard; Secure Input is on with tray/mic/stop/cancel guidance. Two-second **Press Esc again to cancel/discard**. Retry/delete failures have safe specific messages.

Cards: three visible newest-first plus overflow; finite timers pause while tucked, audio leases do not. Capsule springs, layers fade/lift/blur, glyph morphs; reduced motion simplifies transitions and removes breathing/outline animation. ## D. Nine yes/no changes, ordered by first-minute impact

All are **proposals**. **S** = localized UI/copy; **M** = coordinated frontend/state; **L** = cross-layer lifecycle. Sizes are scope, not schedules. Implementation targets below are not files changed by this audit. `O/` retains the onboarding prefix from A.

### Behaviour: speed, feedback, recovery

**1. Prepare offline dictation while permissions proceed. — M**  
**Before:** download/verify/list → Continue → permissions (`O/OnboardingDesktop.tsx`). **After:** compact **“Preparing offline dictation · 42%”** footer while permissions and shortcut/mic checks proceed; practice waits for verified+selected engine. Cancel/retry in place, no invented ETA, no silent cloud fallback. **Why:** removes serialized idle time; [Windows background feature preparation](https://support.microsoft.com/en-us/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc-fec94565-c4bd-329d-e59a-af033fa5689f) is a precedent, not evidence we can dictate without any ready engine. **Files:** `O/{OnboardingDesktop,useOnboardingDesktop,ReadinessLocalPanel}.tsx`.

**2. Choose language before recommending a model; never reset it on shortcut save. — M**  
**Before:** no question; both save branches write `en` (`O/useOnboardingDesktop.ts::saveHotkeySettings`). **After:** **“I speak [language]”**, existing choice/locale suggestion, supported Auto explicitly available; compatible recommendation, warning before incompatible download; preserve on back/edit/relaunch. **Why:** a beautifully wrong first sentence fails; [Flow languages](https://docs.wisprflow.ai/articles/3152211871-setup-guide), [Handy model guidance](https://handy.computer/docs/getting-started). **Files:** `O/{SourceStep,OnboardingDesktop,useOnboardingDesktop}.tsx`, existing language/capability helpers; no new setting required.

**3. Truthful permission actions + actual mic proof. — M**  
**Before:** Open System Settings even before request; test deferred (`O/{PermissionsStep,MicrophoneCheck}.tsx`). **After:** **Allow microphone** initially, settings action only for manual recovery; Accessibility toggle guidance; return-to-app recheck. Explicit mic test shows real levels: **“We can hear you”** / **“No input yet — try another microphone.”** Silence is not hardware failure; disclose capture and stop on leaving. **Why:** [Typeless](https://www.typeless.com/help/installation-and-setup), [Superwhisper](https://superwhisper.com/docs/get-started/quickstart) demonstrate readiness. **Files:** those components, onboarding hook, existing permission hooks; focused test-meter adapter only if existing API cannot safely supply levels.

**4. Default to an outcome, not engine administration. — M**  
**Before:** equal source cards then Repair/Delete/GPU (`O/{SourceStep,ReadinessLocalPanel}.tsx`). **After:** **“Dictate privately on this Mac/PC”**, one compatible recommendation/size, **Prepare offline dictation**; secondary cloud/LAN and advanced-model choices. No repair/delete/GPU on default path. Resolve “free” against actual license policy. **Why:** [user comparison](https://www.reddit.com/r/superwhisper/comments/1t6u0es/i_compared_superwhisper_to_whispr_flow_my_quick/) values simplicity over setup burden. **Files:** those components and `O/OnboardingDesktop.tsx`.

**5. End on demonstrated success, not an enabled finish button. — M**  
**Before:** finish allowed without practice; actual-input success check already exists (`O/SuccessStep.tsx`, `useTestDictation.ts`). **After:** **“That worked. Now try it in your next message.”** Explicit Skip practice escape; outcome-specific Choose mic / Check shortcut / manual-paste recovery; one optional cross-app handoff, not another wizard. Telemetry remains readable/subordinate, meaning/default unchanged. **Why:** [Aqua Aug 25](https://aquavoice.com/changelog) teaches the cross-app bridge. **Files:** `O/SuccessStep.tsx`, `O/useOnboardingDesktop.ts`, `src/components/tabs/overview/useTestDictation.ts`. No practice text in analytics/new persisted metadata.

**6. Distinguish keypress from microphone-ready. — M**  
**Before:** only dim 0:00 distinguishes pending (`src/pill/{island,renderer}.ts`). **After:** instant **“Opening microphone…”**, then **“Listening”** from real capture-ready event, waveform/start sound. Beginner label can later recede; accessibility announcement remains. Never fake waveform or promise <50 ms without measurement. **Why:** [Apple ready cue](https://support.apple.com/guide/mac-help/use-dictation-mh40584/mac), [Windows Listening](https://support.microsoft.com/en-us/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc-fec94565-c4bd-329d-e59a-af033fa5689f). **Files:** `src/pill/{dom,renderer,glyph}.ts`, `src/pill.css`; preserve generation/readiness contracts.

**7. Honest completion receipt, coordinated with clipboard work. — L**  
**Before:** Pasted / “[App] didn’t accept” can imply target-app observation (`renderer.ts::outcome`). **After:** Pasted only with supporting evidence; otherwise **Text ready** / **Copied — press ⌘V/Ctrl+V**, without blaming target. Keep persistent manual-paste/retry. Change backend contract and UI together, not a global cosmetic rename. **Why:** ownership/change count is not proof of insertion (`plans/083-2.1-beta6.md §7`); practice textarea check is stronger. **Files:** assigned focused `src-tauri/src/writing/clipboard_transaction/` work, minimal existing outcome-emitter wiring, `src/types/paste-outcome.ts`, `src/pill/{renderer,feedback}.ts`. Do not duplicate the clipboard slice or promise universal receipts.

### Visual: hierarchy, legibility, motion

**8. Show a beginner Stop without hover hunting. — S**  
**Before:** hover-only controls, 26px rounds (`renderer.ts::sync`, `pill.css::.round`). **After:** practice gets persistent labeled **Stop**, clearly distinct **Cancel**; thereafter small stable Stop target/keyboard equivalent, generous hit region, not whole-capsule click. Never steal editor focus. **Why:** [Handy’s X warning](https://handy.computer/docs/advanced), [Superwhisper separation](https://superwhisper.com/docs/get-started/interface-rec-window). **Files:** `src/pill/{dom,renderer,action-regions}.ts`, `src/pill.css`, practice wiring.

**9. Spend motion on continuity, not fleeting configuration. — S**  
**Before:** three technical chips for 800 ms, fold, text lift/blur (`renderer.ts::foldStart`, `layers.ts`). **After:** ordinary first take starts with clear Listening; changed input/engine/style gets a readable small notice, not a reading test. Preserve waveform→arc→result, fixed anchor, colors and reduced motion; remove blur from essential text. Chips stay in deliberate peek/settings. **Why:** [preview builds trust](https://news.ycombinator.com/item?id=50032393); [Aqua glass/pet](https://aquavoice.com/changelog) need not become our identity. **Files:** `src/pill/{renderer,layers}.ts`, `src/pill.css`; `src-tauri/src/pill/context.rs` only for default policy.

## E. Do not copy; decisions and verification boundary

- **Compulsory surveys/sign-in/multi-feature tours:** documented by [Flow](https://docs.wisprflow.ai/articles/3152211871-setup-guide)/[Typeless](https://www.typeless.com/help/installation-and-setup), but add work before proof.
- **Pet rewards/glass as the premium proposition:** [Aqua](https://aquavoice.com/changelog) makes pets optional and later adds size/fade controls; decoration does not solve capture/paste uncertainty. Translucency requires background-legibility testing.
- **“Real-time everywhere” / “always local”:** [VoiceInk](https://tryvoiceink.com/docs/realtime-transcription), [Superwhisper](https://superwhisper.com/docs/get-started/interface-rec-window), [Apple](https://support.apple.com/guide/mac-help/use-dictation-mh40584/mac) document conditions; our gate is `src/pill/contracts.ts::islandShowsLiveWords`.
- **Broad context capture / silent auto-submit:** [Superwhisper](https://superwhisper.com/docs/get-started/interface-rec-window) documents clipboard context; [Handy](https://handy.computer/docs/advanced) offers auto-submit, off by default. Our surrounding-context contract prohibits clipboard/screenshots (`plans/083-2.1-beta6.md §4`); a first sentence must not accidentally send itself.

**Founder decisions:** yes/no to each number; resolve “free” (#4); approve degraded clipboard wording with the clipboard slice (#7). No account system, cloud subsidy or brand redesign required.
