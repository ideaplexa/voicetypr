## Results (2026-11-13)

All slices are merged into `release/2.1.0-beta.9`.

| Slice | Outcome |
|---|---|
| A | Ported in six commits. `spoken_punctuation.rs` is byte-identical to `hotfix/2.0.12`; the toggle sits in the 2.1 Polish settings and is off by default |
| B | Log messages are scrubbed before every sink (home directories become `~`, URLs lose credentials and query). Token, path, endpoint and server-name logs removed; the two unused debug commands deleted; `scripts/check-private-logs.mjs` runs first in `pnpm check`. Sidecar error descriptions and stderr forwarding were kept on purpose: they pass the scrubber and are needed to diagnose Parakeet failures. A remote server's error body is no longer stored in failed history, only a fixed category |
| C | `release.yml` starts with a `ci-gate` job (dry runs included) that requires a successful `ci.yml` run on the exact commit with jobs `changes`, `workflow`, `frontend`, `native / build-macos`, `native / build-windows`. CI now also runs on `release/**`. Windows script runs the installer, import, linker-map and Ivy Bridge checks and stops on a failed upload; sidecar `build.sh` fails on a failed protocol check; Vitest ignores `agent/`. None of the workflow changes can run before the first push |
| D | Speaker-labelled uploads run each speaker's text through the deterministic writing stages; AI Polish and output-language transforms are skipped for them, with a warning in history. A plain transcript from the diarized request is reused instead of sending a second request, except when the task is translate-to-English |
| E | One save in flight at a time in the frontend and a lock around `save_settings` in Rust; the legacy sharing password is deleted only once it is in secure storage. Not fixed: a failed save can still leave the remote port and the bulk settings disagreeing (needs the patch-based settings in Phase 2) |
| F | Cloud audio queue holds at most 10 seconds of audio; on overflow the stream fails and the existing whole-recording fallback produces the text. Whisper downloads fail after 30 seconds without bytes |
| G | Sharing uses an identifier derived one-way from the device hash, so the licence device hash never goes on the network; a password-protected host shows a generic name in discovery. OpenCode 1.x now gets its input on stdin (its `run` command reads piped stdin in v1.0.0 and v1.3.0 source), so dictated text is no longer in the process list |
| H | Nothing to port: all four commits are already present on this line in a later form |
| I | Seven ledger rows rewritten with evidence; 14 smoke items marked obsolete, none ticked; eight checks listed as blocking 2.1 stable |

### NEEDS-SMOKE from this plan

- Two machines: discovery, password prompt, connection and self-detection, including a 2.0.x peer.
- Real Soniox and Deepgram keys: speaker-labelled upload keeps labels and applies vocabulary; a plain result costs one request.
- Throttled network: a stalled cloud stream falls back to the whole recording; a stalled Whisper download shows the error.
- Spoken punctuation with local Whisper and a cloud engine, toggle with Polish on and off, line breaks on macOS and Windows.
- OpenCode 1.x Polish with the real CLI.
- Rapid settings changes then restart; failed secure-store migration then an ordinary save.
- Packaged app on macOS and Windows: log files contain no home directory, URL credentials or dictated text; Parakeet diagnostics still appear.
- First dispatch of `release.yml` and the manual Windows release script.
