# 091: Everything in 2.1, launched 27 November 2026

Founder decision, 14 November 2026: the launch is 27 November and all of it
ships in 2.1. This plan is the order of work. It replaces the phase map in
`MASTER-PLAN.md` for anything it names; the master plan's principles, numbers
and privacy rule still apply. Launch message and pricing are in
[090](090-2.1-launch-and-pricing.md).

Status: plan. Nothing below is built unless the "State" column says so.

Tracks run side by side, one worktree and branch per slice, merged into
`release/2.1.0-beta.9` by the integration owner. Code freeze is 25 November;
26 November is for the packaged builds and the last run on both platforms.
